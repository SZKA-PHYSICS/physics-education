# فیزیک‌نما و وب‌سایت آموزش فیزیک

**سفارش‌دهنده و مدیر اعلام‌شدهٔ پروژه:** سیده زهرا کراری، مدرس دانشگاه و دبیر فیزیک، تهران

## راهنمای اجرا و انتشار
روی `fiziknama.html` دوبار کلیک کنید؛ برنامه در مرورگر باز می‌شود. فایل تک‌صفحه‌ای است و برای محاسبات، نیاز به اینترنت یا کتابخانهٔ خارجی ندارد. برای میزبانی عمومی از GitHub Pages روی شاخهٔ `main` و پوشهٔ ریشه (`/root`) استفاده می‌شود؛ انتشار عمومی GitHub Pages باید جداگانه بررسی شود.

## ویژگی‌ها
- چهارده حوزهٔ آموزشی، از حرکت تا نور و الکتریسیته، شاره‌ها، گرما و فیزیک هسته‌ای؛
- کنترل پارامترها، نمایش شماتیک، محاسبه، پاسخ و بازخورد؛
- نگهداری اختیاری پیشرفت در `localStorage` مرورگر همان دستگاه؛
- قابلیت استفاده در صفحه‌نمایش کوچک، جست‌وجوی درس و ذخیرهٔ شناسنامهٔ اعلامی پروژه.

## محدودیت‌ها
شبیه‌سازی‌ها **مدل‌های ساده‌شده** هستند، نه آزمایش علمی با دادهٔ واقعی. فرض‌های معتبر هر مدل در [دامنهٔ اعتبار علمی](docs/SCIENTIFIC_MODEL_SCOPE.md) آمده است. نمره‌های تمرینی گواهی ارزیابی رسمی نیستند.
