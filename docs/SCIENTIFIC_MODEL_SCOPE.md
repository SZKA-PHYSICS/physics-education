# دامنهٔ اعتبار علمی و فرض‌های شبیه‌سازی‌ها

مخاطب: آموزش مفهومی دورهٔ متوسطه، نه کاربرد صنعتی یا پژوهشی. اعداد خروجی از مدل‌های ریاضی حاصل می‌شوند؛ داده‌های آزمایشگاهی اندازه‌گیری‌شده نیستند.

| مبحث | رابطهٔ ساده‌شده | فرض یا محدودیت مهم |
|---|---|---|
| حرکت | `x=v₀t+½at²` | حرکت یک‌بعدی و شتاب ثابت؛ x در این رابطه جابه‌جایی علامت‌دار است |
| نیرو | `ΣF=ma` | چارچوب تقریباً لَخت، جرم ثابت، نیروی خالص |
| انرژی | `Eₖ=½mv², U=mgh` | گرانش یکنواخت نزدیک سطح زمین و تراز پتانسیل مشخص |
| فشار | `ΔP=ρgh` | شارهٔ ساکن و با چگالی ثابت؛ فشار پیمانه‌ای |
| چگالی | `ρ=m/V` | چگالی متوسط؛ شناوری به شرایط واقعی جسم/شاره هم بستگی دارد |
| مدار | `I=V/R` | مقاومت اهمی، منبع ایدئال و صرف‌نظر از جزئیات دما |
| مغناطیس | `B=μ₀I/(2πr)` | سیم مستقیم بسیار بلند، بیرون از سیم و محیط خلأ/هوای تقریبی |
| بازتاب | `θᵢ=θᵣ` | زاویه‌ها نسبت به خط عمود بر سطح، بازتاب آینه‌ای |
| عدسی | `1/f=1/dₒ+1/dᵢ` | عدسی نازک و تقریب پرتوهای نزدیک محور؛ قرارداد علامت |
| موج | `v=fλ` | موج تناوبی؛ در مدل ساده‌شده، انتشار یکنواخت |
| صوت | `v≈331+0.6T` | تقریب تجربی برای هوای خشک نزدیک دمای اتاق، T بر حسب سلسیوس |
| گرما | `Q=mcΔT` | گرمای ویژهٔ ثابت در بازهٔ محدود و نبود تغییر فاز |
| گرانش | `W=mg` | میدان گرانشی تقریباً یکنواخت در مقیاس جسم |
| نیمه‌عمر | `N=N₀2^(-t/T½)` | مقدار مورد انتظار برای شمار بسیار زیاد هسته‌ها، واپاشی آماری |
