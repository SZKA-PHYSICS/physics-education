# دامنهٔ اعتبار علمی و فرض‌های شبیه‌سازی‌ها

مخاطب: آموزش مفهومی دورهٔ متوسطه، نه کاربرد صنعتی یا پژوهشی. اعداد خروجی از مدل‌های ریاضی حاصل می‌شوند؛ داده‌های آزمایشگاهی اندازه‌گیری‌شده نیستند.

| مبحث | رابطهٔ ساده‌شده | فرض یا محدودیت مهم |
|---|---|---|
| حرکت | `x=v₀t+½at²` | حرکت یک‌بعدی و شتاب ثابت؛ x در این رابطه جابه‌جایی علامت‌دار است |
| نیرو | `ΣF=ma` | چارچوب تقریباً لَخت، جرم ثابت، نیروی خالص |
| انرژی | `Eₖ=½mv², U=mgh` | گرانش یکنواخت نزدیک سطح زمین و تراز پتانسیل مشخص |
| فشار | `ΔP=ρgh` | شارهٔ ساکن و با چگالی ثابت؛ فشار پیمانه‌ای |
| چگالی | `ρ=m/V` | چگالی متوسط؛ شناوری به شرایط واقعی جسم/شاره هم بستگی دارد |
| مدار | `I=V/R` | مقاومت اهمی، منبع ایدئال و صرف‌نظر از جزئیات دما |
| مغناطیس | `B=μ₀I/(2πr)` | سیم مستقیم بسیار بلند، بیرون از سیم و محیط خلأ/هوای تقریبی |
| بازتاب | `θᵢ=θᵣ` | زاویه‌ها نسبت به خط عمود بر سطح، بازتاب آینه‌ای |
| عدسی | `1/f=1/dₒ+1/dᵢ` | عدسی نازک و تقریب پرتوهای نزدیک محور؛ قرارداد علامت |
| موج | `v=fλ` | موج تناوبی؛ در مدل ساده‌شده، انتشار یکنواخت |
| صوت | `v≈331+0.6T` | تقریب تجربی برای هوای خشک نزدیک دمای اتاق، T بر حسب سلسیوس |
| گرما | `Q=mcΔT` | گرمای ویژهٔ ثابت در بازهٔ محدود و نبود تغییر فاز |
| گرانش | `W=mg` | میدان گرانشی تقریباً یکنواخت در مقیاس جسم |
| نیمه‌عمر | `N=N₀2^(-t/T½)` | مقدار مورد انتظار برای شمار بسیار زیاد هسته‌ها، واپاشی آماری |

این منابع برای **راستی‌آزمایی آموزشی** معرفی شده‌اند؛ به معنای تأیید رسمی نرم‌افزار از سوی مؤسسات یادشده نیستند. محتوا باید پیش از استفادهٔ گسترده و در بازنگری‌های بعدی توسط دبیر متخصص بررسی شود.


## دامنهٔ مدل‌های ۱۶ آزمایشگاه تخصصی افزوده‌شده در نسخهٔ 1.2.0

| مدل | روابط و فرض‌های کلیدی | محدودیت‌ها |
|---|---|---|
| اندازه‌گیری سطح | تبدیل سانتی‌متر به متر، A=LW | مستطیل دقیق، بدون تحلیل آماری عدم قطعیت |
| توان الکتریکی | P=VI، E=Pt | توان ثابت، نه پیش‌بینی واقعی روشنایی |
| رسانش گرما | P=kAΔT/d | حالت پایا و دیوارهٔ تخت، ثابت بودن k |
| میدان سیم‌پیچ بلند | B≈μ₀NI/ℓ | سیم‌پیچ بلند، هوا، اثر لبه‌ها ناچیز |
| شکست نور | n₁sinθ₁=n₂sinθ₂ | محیط همگن، هندسهٔ پرتویی؛ بررسی بازتاب کلی |
| اهرم | F₁r₁=F₂r₂ | تعادل ایستا، اهرم بدون جرم و اصطکاک |
| شناوری | F_b=ρgV | جسم کاملاً غوطه‌ور؛ بدون مدلسازی تعادل شناوری جسم آزاد |
| گرمای نهان | Q=mL، t=Q/P | دمای ذوب ثابت، گرم‌کن ایدئال |
| قانون اول | ΔU=Q−W_by | قرارداد علامت مشخص، سامانه بسته |
| کولن | F=k|q₁q₂|/r² | دو بار نقطه‌ای و ساکن در خلأ |
| خازن تخت | C≈ε₀εᵣA/d، U=½CV² | اثر لبه‌ای ناچیز و دی‌الکتریک خطی |
| نیروی لورنتس | F=|q|vBsinθ | میدان همگن و محاسبهٔ بزرگی نیرو |
| القای فاراده | |ε|=N|ΔΦ|/Δt | بزرگی نیروی محرکهٔ متوسط، نه جهت آن |
| آونگ | T≈2π√(L/g) | زاویه کوچک، اصطکاک ناچیز |
| پراش تک‌شکاف | sinθ₁=λ/a | فرونهوفر، شکاف و نور ایدئال |
| فوتوالکتریک | K_max=hf−φ برای hf≥φ | فلز ایدئال، تابع کار ثابت |

**راستی‌آزمایی برنامه‌ای:** نمونه‌مقادیر کولن، شناوری، القا، خازن، آونگ، فوتوالکتریک، شکست و نیروی مغناطیسی با روابط پایه مقایسه می‌شوند. این تست‌ها جایگزین مطالعهٔ موردی همهٔ ورودی‌ها و مرور مستقل علمی نیستند.
